# storporate.frontend

Frontend application for the Storporate platform.

Built with [Next.js](https://nextjs.org) (App Router), TypeScript, Tailwind CSS, and [shadcn/ui](https://ui.shadcn.com).

See also: [storporate.backend](https://github.com/sn-shatabdy/storporate.backend)

## Getting Started

1. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_BASE_URL` to your local backend URL (default: `http://localhost:5056`).
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
